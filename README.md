# Fitzgerald Amaniampong

Backend and platform engineering portfolio focused on reliable workflows, durable data and practical operating controls.

My portfolio focuses on Java/Spring, TypeScript and Python, with testable examples of API design, authorization, idempotency, database recovery and observability.

## Engineering focus

- **Backend reliability:** explicit state transitions, duplicate-request handling, bounded retries and recovery.
- **Platform controls:** tenant boundaries, least privilege, audit history and approval gates.
- **Operational clarity:** clear run instructions, architecture decisions, tests and honest implementation status.
